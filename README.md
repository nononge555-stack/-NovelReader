# NovelReader

NovelReader は、ローカルに保存したWeb小説のPDFをブラウザ上で読みやすい形へ変換して楽しむための、オープンソースのWeb小説リーダーです。

現在は **ハーメルン** と **小説家になろう** から保存した対応PDFを、ブラウザ内だけで解析してライブラリへ追加することを中心に開発しています。

> [!IMPORTANT]
> NovelReader は各小説投稿サイトの公式ツールではなく、各サイト運営者とは提携していません。PDFや抽出した本文をNovelReader側のサーバーへ送信せず、ブラウザ内だけで処理します。

## 現在の対応PDF

### ハーメルン

**縦書きファイル出力 →「縦書きPDF（文庫・特殊タグ一部あり）」**

- 縦書きの列順を座標から復元
- 話境界を検出
- タイトル・作者名を取得
- ページ番号 / 柱 / 奥付を除外
- ルビを暫定的に括弧表記で保持

横長版、特殊タグなし版など、別の出力設定はまだ対応対象外です。

### 小説家になろう

小説家になろうから出力した縦書きPDFに対応しています。

現在のパーサーでは次を行います。

- 表紙から作品タイトル・作者名を取得
- ファイル名がNコード形式の場合はNコードを取得
- なろうPDF固有の話タイトル列の位置から話境界を検出
- 「第○話」のような名前に限定せず、任意の話タイトルに対応
- 前書き / 本文 / 後書きを同じ話へまとめる
- ページ番号を本文へ混ぜない
- 小さい縦書き文字をルビとして検出し、暫定的に括弧表記で保持
- PDF内に文字列として残る挿絵タグは本文から除外
- 大規模PDF向けに複数ページを小さな単位で並列解析

最初の検証には `N0921ED.pdf` 形式の実PDFを使用しています。実PDFそのものはリポジトリへ同梱しません。

## 現在できること

- GitHub Pages上で動作する静的Webアプリ
- PDF選択による作品追加
- PDFのドラッグ＆ドロップによる作品追加
- 追加成功 / 失敗のトースト通知
- トップページで作品を追加した場合の保存後リロード
- IndexedDBへの作品保存
- リロード後のライブラリ復元
- 前話 / 次話への移動
- 読書位置の保存
- 紙 / ダークテーマ
- 文字サイズ・行間・本文幅の変更

## PDF解析の流れ

PDF取り込みには Mozilla PDF.js (`pdfjs-dist`) を使用しています。

```text
PDFを選択 / ドロップ
  ↓
ブラウザ内でPDF.jsが解析
  ↓
PDF形式を判定
  ├─ ハーメルン用パーサー
  └─ 小説家になろう用パーサー
  ↓
文字と座標から本文順・話境界・ルビ等を復元
  ↓
NovelReaderの Novel / Chapter へ変換
  ↓
IndexedDBへ保存
  ↓
Readerで表示
```

サイトごとのPDFレイアウト差は、共通処理へ無理に押し込まず専用パーサーで扱います。作品固有の記号列や表現をサイト共通仕様として特別扱いしない方針です。

## 現在の制限

- ルビはHTMLの `<ruby>` としてはまだ保持せず、括弧表記へ変換します。
- 挿絵そのものの取り込みはまだ行いません。
- 段落復元はPDF上の座標・字下げ・列間隔を利用したヒューリスティックです。
- 保存済み作品をライブラリから削除するUIはまだありません。
- 対応済みと明記していないPDF出力形式は正しく解析できない場合があります。

## ローカル保存とプライバシー

NovelReaderは、インポートしたPDFや小説本文を外部サーバーへアップロードしません。

選択したPDFはブラウザ内のJavaScriptで解析します。解析後はPDFファイルそのものではなく、タイトル・作者・各話本文などの作品データをIndexedDBへ保存します。そのため、同じブラウザではページをリロードしてもライブラリから作品を再度開けます。

ブラウザのサイトデータを削除した場合や、IndexedDBを利用できない環境では保存済み作品が失われる場合があります。

## 著作権について

NovelReader自体は小説作品を提供・配布しません。

利用者は、読み込むPDFや文書を利用する権利があることを自身で確認してください。第三者の著作物をGitHub等へ再配布する用途は想定していません。

## ローカル開発

Node.js 22 以降を推奨します。

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
npm run preview
```

## GitHub Pages

`main` ブランチへのpushで `.github/workflows/deploy-pages.yml` が実行され、GitHub Pagesへデプロイされます。

## ロードマップ

詳細は [PLAN.md](./PLAN.md) を参照してください。作業単位は [TASKS.md](./TASKS.md) で管理します。

当面は対応済みPDFの読み込み精度を優先します。

1. ハーメルン / 小説家になろうPDFの解析精度を上げる
2. 段落・ルビの復元精度を上げる
3. 長編PDFの読み込み速度・メモリ使用量を改善する
4. ローカルライブラリの削除・更新操作を追加する
5. Readerの縦書き表示・目次・検索・ブックマークを追加する
6. 必要になった段階で別PDF形式 / EPUB / TXT / HTMLなどへ拡張する
