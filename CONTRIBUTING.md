# Contributing to NovelReader

Thanks for considering a contribution.

## Development

```bash
npm install
npm run dev
```

Before opening a pull request:

```bash
npm run build
```

## Pull requests

- Keep changes focused and reasonably small.
- Explain user-visible behavior changes.
- Update `PLAN.md` or `TASKS.md` when the scope or milestone changes.
- Do not commit copyrighted novel text or PDF files unless redistribution rights are clear.
- Do not add document uploads, telemetry containing document text, or external processing without an explicit design discussion.

## Code style

- Use TypeScript strict mode.
- Prefer small components and pure helpers.
- Keep importer-specific code behind adapters.
- Use semantic HTML and accessible controls.

## Sample data

Tests, examples, and screenshots should use original or redistributable content only.
